About This Tool

Midjourney's --ar parameter controls the shape of the image it generates — the first number is width, the second is height, and a bigger first number makes a wider image while a bigger second number makes a taller one.

One thing that trips people up: --ar can't contain decimals. A cinematic 2.39:1 ratio has to be typed as --ar 239:100 instead, or Midjourney rejects it. This tool handles that conversion for you automatically, whether you're picking a preset or entering your own numbers.

Frequently Asked Questions

What does --ar actually do?

It sets the width-to-height shape of the image. By default Midjourney generates square images (1:1) — adding --ar lets you make it wide, tall, or anything in between.

Can I use any ratio I want?

Most whole-number ratios work fine. Decimals aren't allowed — you'd need to convert something like 1.85:1 into a whole-number equivalent first. Very extreme ratios can also produce less predictable results, so sticking close to common shapes tends to work best.

Does this work with every Midjourney version?

The code itself works with any version, but older versions support a narrower range of ratios than newer ones. If a ratio doesn't render as expected, try a more standard one like 16:9 or 4:3.

Where do I put --ar in my prompt?

At the very end — after your written description and after any other parameters you're using.
