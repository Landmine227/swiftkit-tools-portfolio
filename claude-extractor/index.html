Why this exists

AI chat logs mix explanation and code together, and a single answer can contain several separate files. Copying each one by hand means scrolling back and forth, missing a block, or grabbing the wrong version after a few rounds of edits.

This tool reads the whole conversation at once, finds every fenced code block, and hands each one back as its own file — named by the language it's written in, so you're not stuck renaming untitled.txt six times.

Common questions

Does this upload or store my conversation?

No. Everything runs locally in your browser. Nothing you paste is sent anywhere or saved after you close the tab.

What happens to code blocks without a language tag?

They're saved as a plain .txt file so nothing gets lost, even if the formatting wasn't perfect.

Does this only work with Claude?

No — it works on any text with standard triple-backtick code fences, so logs from ChatGPT, Gemini, or your own notes work the same way.
