About This Tool

Design tools routinely export SVGs full of things a browser never needs: editor-specific metadata (Inkscape and Sodipodi attributes are common offenders), XML comments, empty attributes, and coordinate values with far more decimal precision than any screen can actually render. This tool strips all of that out.

It's deliberately conservative about IDs — gradients, clip-paths, and masks that reference an ID elsewhere in the file are left completely alone, so referenced elements never silently break. This trims metadata and precision; it does not attempt to restructure or recompress the path data itself.

Frequently Asked Questions

Will this break gradients or clip-paths in my SVG?

No — element IDs and every reference to them (like fill="url(#gradient1)") are left untouched specifically to avoid breaking those connections.

What does the precision slider actually do?

It rounds decimal numbers in path data and coordinates to fewer digits — most icons look identical down to 1-2 decimal places, since screens can't render finer detail than that anyway.

Why keep title and desc tags by default?

Those tags are what screen readers announce for the image, so removing them by default would quietly hurt accessibility. The checkbox is there if you're certain you don't need them.

Is my SVG uploaded anywhere?

No. Everything runs locally in your browser. Nothing you paste is sent anywhere or saved after you close the tab.
